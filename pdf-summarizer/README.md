# AI PDF SUMMARIZER USING GEMINI-FLASH 

  ### This project is an AI-powered PDF summarizer using Gemini Flash AI.
  ### This application extracts the PDF documents and  generates a concise summary.
  ### The application is built with Streamlit and deployed on Streamlit Cloud for easy access.


# Live Demo 

Streamlit App: https://ai-engineer-journey-9xv9zybpqhxpzd8phshhwm.streamlit.app/

# Features

    We can upload documents live directly through the web interface
    It extracts Text automatically from the PDF files 
    It generates a concise summary using Gemini - Flash - Latest

# Frontend

    Streamlit (Python framework used to build the user interface) 

# AI Model 

    Gemini - flash - latest (you can use any other models also) 

# Libraries 

      # google - genai 
      # pypdf 
      # python - dotenv

# Deployment 

    Streamlit - cloud Deployment
